
# SQLite Browser

A powerful Android application for creating, viewing, editing, and managing SQLite database files directly on your phone.

## 📲 Download the App


<a href="https://play.google.com/store/apps/details?id=com.dya.sqlitebrowser">
  <img src="https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png" alt="Get it on Google Play" width="180">
</a>

## ✨ Features

- 📂 Import and export SQLite database files.
- 🗃️ Create and manage database files.
- 📝 View and edit database tables.
- 💻 Execute SQL commands such as `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `CREATE`, and `ALTER`.
- 📄 Import and export data using CSV files.
- 📋 Save copies of database files.
- 🌙 Light mode and dark mode.
- 🔒 Your database files remain stored locally on your device.

## 🛠️ Open Source

This project is open source. Contributions, suggestions, and bug reports are welcome.

**GitHub Repository:**  
https://github.com/w-coding/Sqlite-Browser-for-android

## 🔐 Privacy

SQLite Browser does not require permissions to access your device's files through the Android system file picker. Your database files are managed locally by the application.
